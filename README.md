# AI API Tester

当前版本：`0.4.20`

AI API Tester 是一个基于 Node.js、Express、HTML、CSS 和 JavaScript 的本地 Web 工具，用于测试 OpenAI Compatible API。

获取到的模型列表、模型选择、最近一次检测结果和批量测试开始时间会保存在当前浏览器本地，刷新页面后自动恢复。

组合测试支持自定义测试内容，默认发送 `Hello`。

测试区域提供“组合测试”“独立测试”“对话测试”和“多模型对比”四种模式。对话测试用于与一个站点的一个模型进行多轮交流；多模型对比会同时向多个已勾选站点发送相同内容。

## 当前功能

- 保存一个或多个 API 站点，包括名称、Endpoint 和 API Key
- 从所选站点获取、汇总、搜索和选择 `/models` 模型
- 调用 `/chat/completions` 测试聊天模型
- 统一按“所选站点 × 所选模型”生成测试任务
- 支持全选、清空选择、测试进度和停止测试
- 同时最多发起 3 个独立请求
- 显示 HTTP 状态、响应时间、返回内容和明确错误原因
- 显示请求模型、返回模型与模型一致性检测结果
- 对话测试：任意已选择站点的任意模型，多轮上下文连续保留
- 多模型对比：仅显示“选择测试站点”中勾选的站点，每个站点独立选择模型并并行测试
- 对比结果以独立结果卡片展示，便于逐个查看响应、状态和错误信息
- 站点表和独立测试表支持眼睛按钮，一键隐藏或显示所有端点
- 对话测试和多模型对比支持最长 5 分钟的上游等待时间，并可手动停止

## 模型一致性检测

检测采用保守的分级策略，避免仅因名称不同就直接判定异常：

- `✅ 模型匹配`：规范化后的请求名称与返回名称一致
- `⚠️ 可能存在模型映射`：同系列、同主要版本，但存在 `latest`、`turbo`、`mini` 等别名差异；或信息不足以确认版本冲突
- `🚨 模型版本明显不一致`：可以明确解析出模型系列或主要版本，并确认两者不同
- `❓ 无法判断`：API 没有返回 `model` 字段，或失败响应没有足够信息

该结果只反映 API 响应中模型名称的一致性，不对模型真实性作绝对结论。

## API 站点与模型测试

在“API 站点管理”中保存站点名称、Endpoint 和 API Key。站点配置保存在当前浏览器的 `localStorage` 中，不会写入项目文件；API Key 在站点列表中只显示掩码。清除浏览器站点数据会同时删除这些配置。

选择一个或多个站点后，点击“获取所选站点模型”汇总模型列表，再勾选需要测试的模型。点击“开始批量测试”后，系统按“所选站点 × 所选模型”生成全部组合任务，每个组合独立调用 `/chat/completions`，请求内容为 `Hello` 并固定使用 `temperature: 0`，同时最多运行 3 个请求。

选择数量决定测试方式：1 个站点 × 1 个模型是最简单的单项测试；选择更多站点或模型时自动扩展为组合批量测试。

统一结果表记录站点名称、Endpoint、请求模型、返回模型、一致性、状态、HTTP、响应时间、返回信息和错误信息。每条成功结果都可以展开“查看内容”，并支持停止尚未完成的测试。

### 对话测试

在“对话测试”中选择一个已勾选站点和该站点的模型，输入消息后发送。系统会保留当前会话的消息上下文，适合检查模型的连续对话能力；“清空对话”会删除当前页面中的上下文。对话请求最长等待 5 分钟，等待期间可以点击停止。

### 多模型对比

多模型对比只使用上方“选择测试站点”已经勾选的站点，不会把未勾选站点列入选择范围。为每个站点选择一个模型后输入统一测试内容，例如：

```text
站点 1 × 模型 A
站点 2 × 模型 B
站点 3 × 模型 C
```

点击“开始多模型对比”后，系统同时发送请求。每个模型的结果显示为一个独立对话框式结果卡片，包含站点、模型、状态、耗时和完整响应；失败请求会显示错误原因。该模式最长等待 5 分钟，也支持停止未完成请求。

### 端点显示控制

站点列表和独立测试表的“端点”列标题右侧提供眼睛按钮。点击后可隐藏下方所有 Endpoint，再次点击即可恢复显示；隐藏只影响当前页面展示，不会修改已保存配置。

HTTP 栏会显示状态码、简短名称和状态图标。鼠标悬停或键盘聚焦时，会通过自定义 Tooltip 显示详细原因和处理建议；状态码说明集中维护在 `public/statusCodes.js` 中。

## 环境要求

- Node.js 18 或更高版本
- npm

## 首次运行

```powershell
npm install
npm start
```

也可以直接双击 `启动测试.bat`。脚本会检查 Node.js 和依赖，然后启动服务。

浏览器默认打开：<http://localhost:3000>

## 测试

```powershell
npm test
```

不希望启动时自动打开浏览器，可以使用：

```powershell
$env:NO_OPEN_BROWSER='1'
npm start
```

健康检查地址：<http://localhost:3000/api/health>
